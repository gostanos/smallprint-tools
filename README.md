# Small Print tools

The open parts of [Small Print](https://smallprint.dev), which keeps a record of the text that MCP servers, skills and plugins hand to an AI agent and tells you when that text changes.

| Folder | What it is |
|---|---|
| [lab/](lab/) | The disclosure lab: does an AI agent follow a sentence added to a tool description? The harness, the cases, every run and the report. |

The command (`smallprint` on npm), the MCP server (`smallprint-mcp`) and the Claude Code plugin will move here from their current repository.

Each folder carries its own licence file. The site itself is not part of this repository.
